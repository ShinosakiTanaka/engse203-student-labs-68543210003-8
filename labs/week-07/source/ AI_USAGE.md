## ครั้งที่ 1

**ถามอะไร**

* ตรวจสอบว่า Automated Test ใน CP16 ทำครบตามโจทย์หรือไม่ และตรวจสอบผล `npm test` ว่าผ่านหรือไม่

**AI ตอบว่าอย่างไร (สรุปสั้น)**

* AI ตรวจสอบรายการ Test ที่ต้องมีทั้งหมด 6 เคส ได้แก่

  1. `GET /api/requests` ต้องได้ `200` และเป็น array
  2. `GET /api/requests/:id` ที่มีอยู่ ต้องได้ `200`
  3. `GET /api/requests/:id` ที่ไม่มี ต้องได้ `404`
  4. `POST` ข้อมูลถูกต้อง ต้องได้ `201` และ `status: "pending"`
  5. `POST` ข้อมูลไม่ครบ ต้องได้ `400`
  6. ตรวจสอบ CORS header
* จากผลการทดสอบครั้งแรกพบว่า 5 เคสผ่าน และมี 1 เคสไม่ผ่าน เพราะ Test ใช้ ID `1` แต่ข้อมูล Seed ใช้ ID `REQ-001`

**ใช้ส่วนไหน / แก้เองตรงไหน**

* ใช้ AI ช่วยตรวจสอบผล `npm test` และวิเคราะห์สาเหตุของ Test ที่ไม่ผ่าน
* แก้ในไฟล์ `tests/api.test.js` โดยเปลี่ยน

  * `/api/requests/1` เป็น `/api/requests/REQ-001`
  * `assert.equal(res.body.id, 1)` เป็น `assert.equal(res.body.id, 'REQ-001')`

## ครั้งที่ 2

**ถามอะไร**

* หลังจากแก้ Test แล้ว ต้องตรวจสอบอย่างไรว่างาน CP16 ผ่านครบตามโจทย์

**AI ตอบว่าอย่างไร (สรุปสั้น)**

* ให้รันคำสั่ง `npm test` และตรวจสอบผลลัพธ์ว่ามี Test ทั้งหมด 6 เคส และต้องแสดงผล `pass 6` และ `fail 0`

* ผู้จัดทำเป็นผู้แก้ไขโค้ดใน `tests/api.test.js` และเป็นผู้รัน `npm test`

## สรุป

**ส่วนที่เขียนเองทั้งหมด**

* การเขียน Automated Test ใน `tests/api.test.js`
* การกำหนดข้อมูล `validRequest`
* การเขียนเงื่อนไขตรวจสอบผลลัพธ์ของแต่ละ Test
* การแก้ ID จาก `1` เป็น `REQ-001`
* การรัน `npm test` และตรวจสอบผลการทดสอบ

**ส่วนที่ AI ช่วย**

* ช่วยตรวจสอบว่า Test ทั้ง 6 เคสตรงตามโจทย์ CP16 หรือไม่
* ช่วยวิเคราะห์สาเหตุที่ Test `GET /api/requests/:id` ไม่ผ่าน
* ช่วยอธิบายว่าทำไมต้องใช้ `REQ-001` ตามข้อมูล Seed
* ช่วยตรวจสอบผล `npm test` หลังแก้ไข
