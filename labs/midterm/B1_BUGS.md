## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | `SummaryPanel.jsx : 24` | ตอนวนลูป `.map()` แสดงการ์ดสถิติ ไม่ได้ใส่ prop `key` ให้กับ element ตัวนอกสุด ทำให้ React ติดตามรายการไม่ได้ | ใส่ prop `key={item.label}` ให้กับ element นอกสุดในลูป |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `DashboardPage.jsx : 47` | ใน `useMemo` เขียนเงื่อนไขกรองสถานะ completed ผิด โดยไปเช็ก `request.status === 'in-progress'` ซ้ำกับช่องกำลังดำเนินการ | เปลี่ยนเงื่อนไขจาก `'in-progress'` เป็น `request.status === 'completed'` |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) | `DashboardPage.jsx : 52` | ตัวแปร `filteredRequests` ฟิลเตอร์ค่าตายตัวไว้เฉพาะ `'pending'` เสมอ ไม่ได้ผูกกับ state ที่ผู้ใช้กดเลือก | เปลี่ยนจาก `'pending'` ให้เช็กเทียบกับตัวแปร state `statusFilter` แทน |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน | `RequestDetailPage.jsx : 28` | ใน `useEffect` ไม่ได้ใส่ `requestId` ใน dependency array ทำให้เมื่อ path parameter ใน URL เปลี่ยน หน้าเว็บไม่โหลดข้อมูลใหม่ | เพิ่ม `[requestId, reloadKey]` เข้าไปใน dependency array ของ `useEffect` |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด | `DashboardPage.jsx : 49` | `useMemo` ของ `summary` ใส่ dependency array เป็น `[]` ว่างเปล่า ทำให้คำนวณแค่รอบแรกตอน mount และไม่คำนวณใหม่เมื่อข้อมูลเปลี่ยน | เพิ่ม `[requests]` ลงใน dependency array ของ `useMemo` |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า | `DashboardPage.jsx : 63` | เรียกใช้ `deleteRequest` ซึ่งเป็น async function โดยลืมใส่ `await` ทำให้ state ได้รับค่าเป็น `Promise` แทนที่จะเป็น Array เมื่อนำไป `.filter()` จึงเกิด Error หน้าขาว | ใส่คีย์เวิร์ด `await` ด้านหน้า `deleteRequest(requestId)` ในฟังก์ชัน `handleDelete` |
